# 화면과 사용 흐름

Personal food archive × editorial magazine × tasting notebook. 따뜻한 종이색, 잉크색 활자, 올리브색과 흙색의 제한된 평가 색상, 얇은 선과 여백을 사용합니다. 큰 사진은 사용자 사진이 있는 경우에만 사용하고, 사진이 없으면 번호와 메뉴명이 있는 기록장 표지로 표시합니다.

Collection은 통계 대시보드가 아닌 메뉴의 아카이브입니다. Journal은 월·일 순서의 읽기 흐름을 갖습니다. 메뉴 상세는 누적 기록과 최근 기록을 함께 보존합니다. 장소는 메뉴 탐색을 돕는 보조 축이며 Insights에만 통계를 모읍니다.

Quick Add는 모달과 모바일 하단 시트로 동작합니다. 필수 입력은 메뉴·호불호·재주문이며 상세 입력은 점진적으로 펼칩니다. 기존 메뉴 선택, 로컬 장소 검색, 새로운 장소와 브랜드의 직접 생성을 지원합니다. 외부 지도 검색은 연결하지 않습니다.

호불호는 색뿐 아니라 + / = / −와 글자로 구분합니다. 네이티브 dialog의 키보드 포커스와 ESC, 명시적 입력 레이블, 포커스 표시, 본문 건너뛰기, reduced motion을 지원합니다. 삭제와 데이터 교체에는 영향을 설명하고 확인을 받습니다.

# 제품 방향

PALATE는 식당 평판 대신 **내가 먹은 메뉴에 대한 그날의 경험**을 기록합니다. 데이터의 중심은 EatingRecord입니다. 동일한 메뉴의 반복 식사는 모두 별도 사건으로 남습니다.

평가는 LIKE / NEUTRAL / DISLIKE, 재주문 의사는 YES / MAYBE / NO로 독립적입니다. 별점·공개 프로필·광고·팔로우·타인 평가를 두지 않습니다. 기본 기록은 메뉴와 두 가지 선택만으로 저장할 수 있습니다. 긴 메모, 사진, 장소, 날짜, 가격, 태그는 선택입니다.

누적 선호도는 기록의 최빈 평가입니다. 동률이면 최근 기록의 평가를 사용합니다. 메뉴 상세에서 전체 횟수와 최근 세 기록을 함께 보여주며 이를 예측 알고리즘으로 표현하지 않습니다. 자주 찾는 메뉴는 3회 이상, 호 비율 80% 이상, 최근 기록 호 조건으로 계산하고 메뉴 편집에서 라벨을 바꿀 수 있습니다.

사용자 요청에 따라 서버 인증과 Supabase를 사용하지 않고 로컬 프로필 1개와 localStorage, JSON을 사용합니다. Private는 기록이 외부로 전송되지 않는다는 의미이며 로컬 암호 잠금이나 다중 사용자 접근 제어를 뜻하지 않습니다.

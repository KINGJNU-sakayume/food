# iPhone 15 Pro에서 공유하기

PALATE는 아이폰 공유 메뉴의 **단축어**를 통해 링크를 받습니다. `고르기 → 릴스 보관함 → 아이폰 공유 설정` 또는 설정에서 현재 배포 주소가 들어간 안내와 복사 버튼을 사용할 수 있습니다.

## 한 번만 설정

1. 아이폰 **단축어** 앱에서 새 단축어를 만들고 이름을 **PALATE에 저장**으로 지정합니다.
2. 단축어 세부사항에서 **공유 시트에서 보기**를 켜고 **URL과 텍스트** 입력을 받도록 설정합니다.
3. **URL 인코딩** 동작을 추가합니다. 입력은 **단축어 입력**, 모드는 **인코딩**으로 둡니다.
4. **텍스트** 동작을 추가합니다. PALATE 안내 화면의 주소 앞부분을 붙여넣은 뒤, 공백 없이 **URL 인코딩 결과 변수**를 삽입합니다.
5. **URL 열기** 동작을 추가하고 입력으로 앞에서 만든 **텍스트**를 선택합니다.

텍스트의 전체 형태는 다음과 같습니다. 실제 주소는 배포한 PALATE 주소를 사용해야 합니다.

```text
https://kingjnu-sakayume.github.io/food/#/receive?text=[URL 인코딩 결과 변수]
```

`[URL 인코딩 결과 변수]`는 문자 그대로 입력하는 것이 아니라 단축어 편집기에서 변수로 삽입합니다. 한국어와 링크의 `?`, `&`, `#` 등이 보존되도록 입력 전체를 한 번 인코딩합니다.

## 저장 흐름

인스타그램에서 릴스를 열고 **공유 → 아이폰 공유 시트 → PALATE에 저장**을 선택합니다. PALATE가 열리며 보관함에 추가됩니다. 음식점 선택과 메모는 요구하지 않습니다. 지도나 배민의 음식점 링크도 같은 단축어로 보관할 수 있습니다.

같은 릴스의 추적 파라미터가 달라도 기존 링크 한 개를 유지하고 기존 메모와 연결을 보존합니다. 릴스의 제목·영상·음식점을 자동 추출한 것으로 표시하지 않습니다.

## 저장 공간과 실제 기기 확인

단축어가 여는 브라우저에서 PALATE를 사용하세요. Safari, 다른 브라우저, 홈 화면 웹앱의 localStorage는 공유되지 않을 수 있습니다. 주소나 실행 방식을 바꿀 때는 기존 공간에서 JSON 백업 후 새 공간에서 복원합니다. 이 흐름은 PALATE를 열어 저장하며 인스타그램 안에서 보이지 않게 완료되는 공유 확장은 아닙니다.

자동화 브라우저 테스트는 인코딩된 공유 링크 수신·중복 처리·기존 데이터 보존을 검증합니다. 실제 인스타그램의 iOS 공유 메뉴 동작과 단축어 변수 연결은 사용자의 아이폰에서 최종 확인이 필요합니다. 아이폰에서 직접 생성하는 절차이며, 설치할 수 없는 서명되지 않은 `.shortcut` 파일이나 존재하지 않는 설치 링크를 제공하지 않습니다.

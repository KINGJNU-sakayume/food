# 다음 단계

현재 구현은 로컬에서 완결되는 개인용 첫 버전입니다.

- 사진이 많은 아카이브를 위한 IndexedDB와 별도 사진 묶음 내보내기
- JSON 스키마 마이그레이션과 백업 병합의 충돌 해결
- PlaceSearchProvider 인터페이스 기반의 선택적 지도 검색 연동
- 기간별 음식 종류 변화와 기록 수를 함께 보여주는 비교
- 선택적 기기 내 암호화와 자동 백업 설계

AI 추천, 소셜 기능, 공개 리뷰와 별점은 제품 범위에 포함하지 않습니다. 외부 서버 동기화는 현재 요구 사항인 localStorage + JSON 범위 밖이므로 추가하지 않습니다.

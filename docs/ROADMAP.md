# 다음 단계

현재 구현은 개인 데이터의 로컬 저장을 유지하면서 고르기와 릴스 보관함을 지원합니다. 음식점 메뉴의 실제 자동 연동은 별도의 조회 서비스 연결이 필요합니다.

- 사진이 많은 아카이브를 위한 별도 사진 묶음 내보내기 (사진 원본의 IndexedDB 저장은 완료)
- JSON 스키마 마이그레이션과 백업 병합의 충돌 해결
- 개별 음식점 메뉴 자동 조회 서비스 운영 연결과 실제 출처별 가용성 검증
- 프랜차이즈 수록 메뉴의 갱신 범위 확대
- 기간별 음식 종류 변화와 기록 수를 함께 보여주는 비교
- 선택적 기기 내 암호화와 자동 백업 설계

AI 추천, 소셜 기능, 공개 리뷰와 별점은 제품 범위에 포함하지 않습니다. 외부 서버 동기화는 현재 요구 사항인 localStorage + JSON 범위 밖이므로 추가하지 않습니다.
